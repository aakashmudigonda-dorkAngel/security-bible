AI Security

Quick refresher

Track trust across prompts, retrieved documents, model output, and tool calls. Treat external content and generated output as untrusted. Enforce authorization and validate tool arguments outside the model before using them to read or change data.

Worked example

A knowledge assistant retrieves files for an employee. Filter retrieval using the employee's permissions, allow only narrowly scoped read tools, and require an independent authorization check before a tool accesses a record.

Interview practice

How would you secure a document assistant with access to internal tools?

Map data flows and trust boundaries, scope retrieval and tool access to the user, validate requested actions, and test with untrusted content and fake records. Monitor unexpected tool calls and protect sensitive log fields.
