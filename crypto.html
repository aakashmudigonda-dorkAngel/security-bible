Cryptography Basics

Quick refresher

Encryption protects confidentiality. Authenticated encryption also detects tampering under the key. A hash produces a digest, a MAC authenticates data to parties with a shared secret, and a signature can be verified using a public key.

Worked example

Use a vetted authenticated encryption library for sensitive backups, store keys separately, and test restoration. For password storage, use a salted password hashing function with a calibrated cost.

Interview practice

How would you verify the authenticity of a software update?

Verify a digital signature against a trusted signing key or trust chain. Explain how the client obtains trust, how key rotation works, and how rollback is handled.
