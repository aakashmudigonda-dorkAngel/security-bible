Cloud & Infrastructure Security

Quick refresher

Start with shared responsibility and identify who owns configuration, patching, and monitoring for each service. Use scoped roles and short-lived workload credentials. Review public ingress, data access policies, and cloud control-plane audit logs.

Worked example

A report generator needs read access to one storage prefix. Give its workload identity that narrow permission and use logs to confirm which resources it accesses.

Interview practice

How would you reduce the impact of a compromised workload?

Limit the workload's identity and network reach, isolate environments, prefer short-lived credentials, and monitor privileged actions and unusual data access.
