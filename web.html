Web Application Security

Quick refresher

The browser groups documents by origin, defined by scheme, host, and port. CORS can permit browser scripts to read cross-origin responses. The server still needs to validate input, authorize actions, and protect sensitive state changes.

Worked example

For a profile editor, use bound database parameters, context-appropriate output encoding, and server-side ownership checks. For cookie-based sessions, add suitable cookie settings and CSRF protection for state changes.

Interview practice

How would you review a profile update endpoint?

Trace inputs to data stores and rendered output. Check session validation, authorization on the target record, CSRF protection, data validation, and tests for rejected updates.
