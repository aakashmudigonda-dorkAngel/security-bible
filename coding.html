Secure Coding & Scripting

Quick refresher

Use safe APIs at trust boundaries, validate data against a known schema, and give automation a narrowly scoped identity. Consider retries, partial failures, resource limits, and what gets written to logs.

Worked example

For a script that reviews access grants, parse structured input, collect findings without modifying grants, avoid logging credentials, and return a clear status if collection is incomplete.

Interview practice

What would you review before running a maintenance script in production?

Inspect its permissions, input validation, logging, retry behavior, and impact on partial failure. Test it against representative data and verify that operators can reconcile changes.
