Networking

Quick refresher

DNS resolves names, IP routes packets, TCP provides an ordered byte stream, and TLS protects application traffic. HTTP then defines the request and response. Identify which system terminates TLS and which network links need separate protection.

Worked example

A browser reaches a reverse proxy over HTTPS. The proxy validates the incoming request and opens a separate connection to the application. Restrict the backend to proxy traffic and document where plaintext can exist.

Interview practice

What happens when you open an HTTPS URL?

Walk through name resolution, connection establishment, TLS certificate validation and key negotiation, then the HTTP exchange. Mention cached DNS or reused connections if relevant.
